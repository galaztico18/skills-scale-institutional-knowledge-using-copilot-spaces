# OctaAcme Project Management Docs

This directory contains the core project management process documents used by OctaAcme. Together, they define how the team initiates work, plans delivery, tracks execution, manages risk, releases changes, and continuously improves.

## Overview

OctaAcme follows a simple, repeatable project lifecycle:

1. Initiation — validate the need, align stakeholders, and decide whether to proceed.
2. Planning — define scope, milestones, backlog, and responsibilities.
3. Execution & Tracking — deliver work in small increments, track progress, and address blockers.
4. Release & Deployment — validate quality, ship changes safely, and communicate outcomes.
5. Retrospective & Improvement — capture learnings and turn them into action.

These docs help standardize communication, ownership, and execution across cross-functional teams.

## How to Use This Set

- Start with the [Project Management Overview](./octoacme-project-management-overview.md) for a quick orientation.
- Use the initiation and planning guides before starting a new initiative.
- Refer to execution, risk, and release docs during active delivery.
- Use retrospectives to improve team practices over time.

This documentation acts as the shared baseline for project execution, ensuring alignment across roles and reducing reliance on undocumented tribal knowledge.
